# Portfolio de Darío Ceballos

Web personal: perfil, experiencia y proyectos. Publicada en https://daridoto.github.io

Sitio estático con [Astro](https://astro.build) y CSS propio. Se publica en GitHub Pages
automáticamente con cada cambio en `main`.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # genera dist/
```
